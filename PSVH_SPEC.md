# Prime Sieve Validation Hash (PSVH) Standard

## Overview

PSVH defines a cryptographic verification standard for prime number
lists generated by fastsieve.  The SHA-256 hash of the uncompressed
prime list serves as the canonical identity of a given range.

## Canonical Format

- **Encoding**: Decimal ASCII, one prime per line, Unix LF only
- **No trailing newline** on the last line
- **Hash**: SHA-256 of the uncompressed stream
- **Reference wheel**: 30 (fastsieve `--wheel 30`)

## Distribution

Prime lists are distributed as **gzip -9 compressed** files
(`primes_1e{N}.txt.gz`) due to their size.  The SHA-256 hash
in the accompanying `.sha256` file and in `PSVV_HASHES.json`
is always computed on the **uncompressed** content.

## Verification

```sh
# Verify a compressed prime list against its .sha256 file:
zcat primes_1e9.txt.gz | fastsieve --verify-hash -
```

The `--verify-hash -` flag reads from stdin and compares the
computed hash to the first 64 hex characters of the `.sha256` file.

## Generating Reference Files

```sh
# Generate with reference wheel 30 and hash output:
fastsieve --wheel 30 -o primes_1e9.txt --hash-output primes_1e9.txt 1000000000
gzip -9 primes_1e9.txt
```
